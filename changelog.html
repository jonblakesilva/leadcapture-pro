Changelog

What's New in LeadCapture Pro

Updates, fixes, and improvements

v1.7.1 Latest March 2026
Bug Fixes
  • Fixed 404 error on contact search — GHL v2 API requires POST /contacts/search, not GET
  • Contact duplicate detection now works correctly when checking by phone or email
v1.7.0 February 2026
New Features
  • Workflow enrollment — enroll pushed contacts into a GHL automation workflow in one click
  • Batch push with shared tags and notes for all selected contacts
  • Outreach prompt generator — produces Email, SMS, Loom, LinkedIn, and FB/IG DM copy
  • Audit Video button — opens Loom recorder alongside the business website
  • Marketing Problem Detector — scans prospect websites for Pixel, HTTPS, meta tags
  • Review Gap panel — shows star rating and review count from Google Maps
  • Daily Prospecting System panel on the empty state view
  • GHL tag autocomplete — type to search existing tags in your location
  • Location profiles — save multiple GHL locations and switch between them
  • Export / import settings as JSON (API key excluded from export)
Improvements
  • Opportunity score now shows label (Hot / Warm / Cold / Pass) and color bar
  • Google Maps SPA retry — address and website fields now populate after Maps loads
  • Sidebar tooltips repositioned using fixed positioning to prevent clipping
  • Brand color preset swatches in settings
  • API key character counter with length validation hint
  • Logo URL validator with user-visible warning on load failure
Bug Fixes
  • Business contacts no longer fail with 400 — companyName is sent without firstName/lastName
  • Clipboard copy works correctly (removed deprecated execCommand fallback)
  • Sidebar tooltip no longer clipped by overflow containers
  • storage.onChanged no longer skips enrichment when detail view is already open
v1.6.0 January 2026
New Features
  • Opportunity / marketing score — rates prospects 0–100 based on digital marketing gaps
  • Point of Contact field — save a person's name alongside the business in GHL
  • Skip Lead button — dismiss a contact without pushing
  • Manual contact entry mode — clear detected data and type details manually
  • Session stats in sidebar footer (contacts pushed this session)
  • Auto-open GHL contact page after push (toggle in settings)
Improvements
  • SPA navigation detection — sidebar and button reset correctly on Google Maps navigation
  • Phone formatter validates and enforces E.164 (+1XXXXXXXXXX) before push
  • Rate limiter — queues GHL API requests to stay under 10/sec limit
  • Retry logic on 429 rate limit responses with exponential backoff
v1.0.0 December 2025
Initial Release
  • Contact detection from phone numbers, emails, and schema.org structured data
  • Source detection — Google Maps, Yelp, Facebook, Yellow Pages, and generic web
  • Floating sidebar with Shadow DOM isolation (no style conflicts with host pages)
  • Push contacts to GHL with tags, pipeline, and stage selection
  • Duplicate check before push
  • Multi-step setup wizard with GHL connection test
  • Agency white-label branding (name, logo, color)
